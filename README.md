# Color Recognition using OpenCV

## Project Description
This project uses OpenCV and Python to detect the green color in an image.

The program:
1. Reads an input image.
2. Converts the image from BGR color space to HSV.
3. Defines a range for the green color.
4. Creates a mask to detect the green areas.
5. Displays the original image and the detected green color.

## Technologies Used
- Python
- OpenCV
- HSV Color Space
